## Architecture Decisions

- **No local download** — URL videos never materialized to disk
- **Pseudo-filename strategy** — `url-<hash>` enables unified API with local uploads
- **Fresh cache status** — URL videos always report `"fresh"` (no TTL)
- **URI resolution** — `_resolve_gemini_uri()` handles both local URIs and remote URLs

## Integration Points

- Shares `/gemini/ask` endpoint with local uploads (same request/response format)
- Future yt-dlp integration can download URL videos on-demand (not in scope)
- Hudson can POST to `/upload-from-url` and then call `/gemini/ask` seamlessly
