## Deliverables

### 1. Cache Status Badges (video library template)
Rendered per video from `/videos/list` response:

**Fresh (green badge)**
- Icon/badge: ✓ "Cached"
- Display: "Cached (41 hours remaining)"
- Action: None (cache is active)
- Color: Green (#10b981 or similar)

**Expired (amber badge)**
- Icon/badge: ⚠ "Cache Expired"
- Display: "Cache expired — click to re-upload"
- Action: "Re-upload" button → `POST /videos/upload-to-gemini`
- Color: Amber (#f59e0b or similar)

**Not Uploaded (grey badge)**
- Icon/badge: ○ "Local Only"
- Display: "Local only — not in Gemini cache"
- Action: "Upload to Gemini" button → `POST /videos/upload-to-gemini`
- Color: Grey (#6b7280 or similar)

### 2. Re-upload UI Flow

When user clicks "Upload to Gemini" or "Re-upload":
1. Show spinner/loader on button
2. Show toast notification: "Uploading to Gemini..."
3. `POST /videos/upload-to-gemini` with `{ "filename": "demo.mp4" }`
4. On success (200): refresh `/videos/list`, update badge to green
5. On error:
   - 503: "Gemini API key not configured"
   - 404: "File not found on server"
   - 500: "Upload failed. Try again later."
6. Hide spinner, show toast result

## Implementation Details

### Frontend Data Binding
Assumes `/videos/list` response (per Ripley's contract):
```json
{
  "videos": [
    {
      "filename": "demo.mp4",
      "gemini_cache_status": "fresh",
      "expires_in_hours": 41
    }
  ]
}
```

### AJAX Endpoint Calls
```javascript
// Fetch video list
fetch('/videos/list').then(r => r.json()).then(data => renderBadges(data.videos));

// Trigger re-upload
fetch('/videos/upload-to-gemini', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ filename: 'demo.mp4' })
}).then(r => r.json()).then(data => updateBadge(data));
```
