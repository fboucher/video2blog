## Deliverables

### 1. `/videos/list` Endpoint
- Returns all locally stored videos from `/app/uploads/`
- Enriches each with:
  - `gemini_uri` (from DB) or `null`
  - `gemini_cache_status`: `"fresh"` (< 48h) | `"expired"` (> 48h) | `"not_uploaded"`
  - `expires_in_hours` (only when fresh)
- Queries `db_service.get_gemini_file_info(filename)` to check cache window

### 2. `POST /videos/upload-to-gemini` Endpoint
- Accepts `{ "filename": "..." }`
- Calls `gemini_service.upload_video(filepath)` (runs in background thread)
- Persists URI via `db_service.update_gemini_upload(...)`
- Returns `{ "status": "ok", "uri": "files/...", "gemini_cache_status": "fresh" }`
- Error handling:
  - 400: missing filename
  - 404: file not in uploads dir
  - 503: GEMINI_API_KEY not configured
  - 500: Gemini API error

### 3. `POST /upload` Enhancement
- Now returns `gemini_uri` and `gemini_cache_status` in response
- Optional `gemini_upload_error` key on Gemini failure (non-fatal)

### 4. Removed Endpoints
- ~~`POST /videos/download`~~ (Reka CDN download)
- ~~`POST /reka/refresh-status/<video_id>`~~ (Reka status polling)
